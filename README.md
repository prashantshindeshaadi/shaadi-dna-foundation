# Shaadi DNA Foundation

Design tokens and rules for Shaadi.com. One source of truth for designers,
developers and AI agents.

**479 variables · 10 collections · v1.1**

## Start here

| You want to | Read |
|---|---|
| Build or review UI (people and AI) | `FOUNDATION.md` — the rules |
| Set up the font, or share the type kit | `fonts/README.md` |
| See what changed | `updates/` — newest first |
| Change a token | [Changing it](#changing-it) below |

## Folders

```
FOUNDATION.md   The rules. Which token, what sits on what, what's not allowed.
tokens/         The values. One file per Figma collection, every mode inside,
                plus sh-gradient.json: the 30 sh-gradient colour styles.
fonts/          Lexend-SH: variable TTF + WOFF2, 4 static TTFs, licence.
components/     Component blueprints. Button is specified.
updates/        Change log in plain language, one file per update.
tools/          Python scripts (standard library only).
skills/         Claude Code workflows: /shaadi-dna-update, /shaadi-code-connect.
dist/           Generated by tools/build.py. Git-ignored, never edited.
```

## Using it

Run `python3 tools/build.py`. It writes:

| Output | For |
|---|---|
| `dist/css/tokens.css` | Web. `var(--sh-…)`, gradients as `background: var(--sh-gradient-brand-default)`; dark mode follows the system or `data-theme="dark"`; breakpoints at 768 / 1024px |
| `dist/android/` | Android. Copy into `app/src/main/res/`; night, sw600dp / sw840dp and `drawable/sh_gradient_*` already split |
| `dist/ios/SHTokens.swift` | iOS. `SH.Color.backgroundDefault.color`, `SH.Space.step16`, `SH.Radius.card`, `SH.Gradient.brandDefault.view` |
| `dist/json/tokens.json` | AI agents and tooling. Resolved values with descriptions |
| `dist/sh-typo-kit.zip` | The type kit to share: fonts + text styles for Figma, web, Android, iOS |

```css
.card {
  background: var(--sh-background-default);
  color: var(--sh-text-primary);
  padding: var(--sh-space-padding-card);
  border-radius: var(--sh-radius-card);
}
```

Typography on Android and iOS comes from the kit (`ShTypography.kt`,
`ShTypography.swift`), not from `dist/android` or `SHTokens.swift`.

## Changing it

Values change in Figma, never here.

```bash
python3 tools/import.py <figma-export.zip>   # variables: shows every change, asks before writing
python3 tools/import.py <styles.json>        # sh-gradient styles, saved from tools/read_styles.js
python3 tools/check.py                       # aliases, descriptions, scopes, fonts, 64 contrast pairs
python3 tools/build.py                       # regenerate dist/ and the type kit
python3 tools/new_update.py "Short title"    # start the log entry in updates/
```

Commit the token files, the update entry and any `FOUNDATION.md` change
together. CI runs `check.py` and `build.py` on every push; a failing contrast
pair or broken alias can't merge.

| Script | Does |
|---|---|
| `import.py` | Merges a Figma variables export (or the styles JSON) into `tokens/` |
| `read_styles.js` | Run in Figma: reads the `sh-gradient` colour styles |
| `gradients.py` | Turns `sh-gradient.json` into CSS, Android drawables and Swift |
| `check.py` | Validates tokens; exits non-zero on any failure |
| `build.py` | Writes `dist/` for web, Android, iOS, JSON, and the type kit |
| `typo_kit.py` | The type kit part of the build |
| `codesyntax.py` | Figma Dev Mode code names; `--plugin` writes the apply script |
| `export_figma.py` | Writes `tokens/` back out as Figma variable files |
| `new_update.py` | Starts an `updates/` entry |
