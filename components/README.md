# Components

One file per component, describing it in tokens. A component is only "in the
system" when its file here is complete.

Each blueprint covers: anatomy, sizes, variants, a token per state, and the
rules for when to use it. Follow the shape of `button.md`.

Building a screen that needs an unspecified component? Build it from the rules
in FOUNDATION.md and flag it, so it can be specified properly rather than
becoming an accidental standard.
