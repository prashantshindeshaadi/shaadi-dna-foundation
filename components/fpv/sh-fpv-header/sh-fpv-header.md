# sh-fpv-header

**Purpose:** Name, age and basics at the top of the content sheet, with status tags and trust badges.

**Built from:** sh-tag-fpv (Active Now, Promoted; sh-tag Strong / Small) + badges.

**Switches:** Case = where she lives / long community name.

**Rules:** profile manager reads "Managed by {Self / Parent / Sibling / Relative / Friend}", never "Created by".

**Taps:** a trust badge → sh-fpv-sheet-trust-markers with the matching Case.
