# sh-fpv-requests

**Purpose:** Her pending requests, in their own section below Compatibility and above About.

**Built from:** sh-fpv-section-title + sh-request-card.

**Switches:** Count = number of pending requests shown (up to 3; more shows "See all N").

**Rules:** drops when there are no pending requests. A request stays until the viewer acts. A Connect invitation is not a request (it changes the action bar). The chip on the photo "N requests from {name} · View" scrolls here.
