# sh-list-default

**Purpose:** One list row for settings, payment options, benefits, add-ons, summaries and inbox conversations. Leading None/Icon/Icon circle/Pictogram/Avatar/Control; Trailing None/Chevron/Value/Tag/Toggle/Action/Meta. Style Default (16 side padding) or Inline (inside a card, no side padding).

Trailing Meta = time plus unread sh-indicator, for inbox conversations (Leading Avatar).

Part of sh-list (Type=Default). Siblings: sh-list-preference (partner preference match) · sh-list-report (reports: open / download / locked / upgrade) · sh-list-score (pictogram + points) · sh-list-highlight (pinned strip) · sh-list-grouped (rows sharing one outline).
