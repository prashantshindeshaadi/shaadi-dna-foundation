# sh-list

**Purpose:** One list row for settings, payment options, benefits, add-ons, summaries and profile facts.

**Types:** Default (any Leading × Trailing) · Preference (partner preference, Match / No match, Collapsed) · Report (reports and documents, Locked, Upgrade) · Highlight (pinned information strip) · Score (pictogram + value, Locked) · Grouped (rows sharing one outline: Single / Start / Middle / End).

**Default:** Leading None/Icon/Icon circle/Pictogram/Avatar/Control; Trailing None/Chevron/Value/Tag/Toggle/Action. Trailing Meta = time plus unread sh-indicator, for inbox conversations (Leading Avatar).

**Keywords:** conversation, inbox row, chat list, list, row, list item, cell, menu item, setting row, payment option, benefit, summary, preference, match, report, download, score, koota, highlight, pinned, grouped, outlined group
