# sh-list

**Purpose:** One list row for every list in the app. Pick a Type — its own options appear under Row.

**Types:** Default (settings, payments, benefits, summaries, inbox: Leading / Trailing / Style) · Preference (partner preference: Match / No match, Read More / Hide) · Report (reports: Open / Download / Premium lock / Locked / Upgrade) · Score (pictogram + points, Locked) · Highlight (pinned strip) · Grouped (rows sharing one outline: Single / Start / Middle / End) · Info (profile detail: icon + text, one or two lines, plain or masked).

**Built from:** sh-list-default, sh-list-preference, sh-list-report, sh-list-score, sh-list-highlight, sh-list-grouped, sh-list-info (exposed as Row).

**Keywords:** list, row, list item, cell, menu item, setting row, payment option, benefit, summary, conversation, inbox row, preference, match, read more, report, download, locked report, upgrade, score, koota, highlight, pinned, grouped, outlined group
