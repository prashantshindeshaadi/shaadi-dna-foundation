# sh-tab-item

**Purpose:** one tab. Style Underline = one tab in a horizontal tab row (New · Daily · My Matches · Near Me); Segmented = one segment inside sh-segmented-control; Vertical = one side tab with a left indicator (desktop settings, account sections). Selected true/false; optional count and notification dot. For a ready row or column, use sh-tab-group.

**Keywords:** tab, tab item, single tab, secondary nav, segment, filter tab, vertical tab, side tab, count
