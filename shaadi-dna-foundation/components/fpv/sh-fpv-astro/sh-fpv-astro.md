# sh-fpv-astro

**Purpose:** Astro Compatibility on the profile (premium feature: the title keeps its gold badge).

**Built from:** sh-fpv-section-title + score / report rows / light card + sh-button.

**Switches:** State = who has added birth details and the viewer’s plan. Chart = North (Guna, of 36) or South (Porutham, of 10). Verdict = off in v1 (label + line as one switch).

**Rules:** the score shows only when both have added and it is 18/36 or more (South 6/10, to confirm). Missing details use the light card. You & Her is a different feature; never mix them.

**Taps:** See full match → Astro match sheet · Ask {name} to add → Request sent · Add my birth details · Unlock → premium plans · download report (Premium, 10 a day).
