# sh-fpv-section-title

**Purpose:** Title of every FPV section.

**Switches:** Title. Show badge = gold premium badge for premium features (Astro, Contact, Education & Career, Photo Album). Show action = the Action button (exposed: pick label and type in the panel).

**Rules:** Unlock (Premium Soft) only for a Free viewer on gated content; Unlock opens the premium plans page. Tit-for-tat states show no button unless the section is a premium feature (Astro keeps its badge). View Contact / View album use the same action.
