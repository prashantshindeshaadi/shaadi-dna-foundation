# sh-avatar-silhouette

**Purpose:** The no-photo silhouette art, one variant per Gender; white with soft edges so it works on any background. An asset: replace the art in a variant, or add a variant for a new case, and every sh-avatar-placeholder and sh-overlay that uses it updates. Keep each figure centred in its square with an even margin.
