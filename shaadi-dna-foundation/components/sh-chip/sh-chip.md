# sh-chip

**Purpose:** one size. Type Choice = selectable filter / option chip (base, 32 tall, single line, states + Selected). Type Info = read-only fact chip (Hindu, Mumbai, 7/9 Preference match): one state, soft border, supporting text above the label shown by default (turn Show supporting label off for a one-line 32 chip).
